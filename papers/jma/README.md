# Journal of Mathematics and the Arts submission

[DRAFT1.md](DRAFT1.md) is a JMA **Research Article** on the geometry and the images, and is the project's current paper. Requirements below are from the journal's instructions for authors (Taylor & Francis, updated 27 November 2026); check them again before submitting.

## Requirements

| Item | Requirement |
| --- | --- |
| Length | Research Article up to 15,000 words; abstract up to 200 words; any number of keywords |
| Structure | Follows the argument; theorem–proof organization is welcome, using the template's theorem styles |
| Spelling and quotes | British spelling with -ize (visualize, colour, centre); single quotation marks |
| Format | Word or LaTeX using the T&F template. For LaTeX, upload a PDF plus a zip of the source; figures as separate files |
| References | T&F standard APA style |
| Review | Single anonymous, by one independent expert; preprints allowed, but anonymity is then not guaranteed |
| Figures | 300 dpi for colour at final size; colour is free online, but print colour costs £300 per figure (£50 each after the fourth) |
| Graphical abstract | **Mandatory**: an image 525 px wide, uploaded separately as `GraphicalAbstract1` (JPG, PNG or TIFF) |
| Statements | Disclosure, funding, declaration of generative AI use and data availability statement, all required |
| Optional | Video abstract; supplemental material (videos, files) hosted on Figshare; image descriptions (alt text) |
| Fees | No submission or page charges; open access optional, with a fee |
